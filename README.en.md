## Why SaturX?

### 📈 Viewer boosting (накрутка зрителей)

- Set your channel and target viewer count.
- Use **SOCKS5 proxies** so each connection has its own IP — safer and more stable.
- Start and stop from the same dashboard; stats in one place.
- One license covers both the dashboard and the viewerbot.

### 💬 Chat activity without the tab chaos

- **Multiple Kick accounts** — add several accounts, switch with one click.
- **Message presets** — save lines in a text file, send with one click from the chosen account.
- **Auto-send** — schedule messages from a selected account so the chat stays active.
- Channel chat and stream are embedded in the dashboard — no need to juggle tabs.

### 🔒 Security: proxies and control

- **SOCKS5 per account** — each account can use its own proxy (file or in-app settings). Your main IP stays out of the loop.
- **License by key** — activation tied to your device; renewal and revoke are handled by the seller.

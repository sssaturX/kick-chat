Connect Kick

Enter your app credentials from developers.kick.com and the channel you chat in. You can minimize the console — everything else is here.

Save Client ID, Secret, and channel first — without them, Add account cannot connect Kick.

In Kick, set Redirect URL to the same address SaturX uses: http://localhost:8080/oauth/callback (port = DASHBOARD_PORT). If needed, add to .env: KICK_REDIRECT_URI=...

After saving, the app restarts and you can continue (license, accounts).

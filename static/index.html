How to add Kick accounts
  1. Create an app at Kick Developers and set the Redirect URL to match this app (see below — must match KICK_REDIRECT_URI in .env or the default).
  2. On first run, enter Client ID, Client Secret, and channel slug (the stream you chat in).
  3. If a license is required, activate your key first, then return here.
  4. Click Add account — a new tab opens; press Continue to Kick there (no auto-redirect). When you see Done, close the tab and refresh this page (F5).
  5. Optional: set a display name and SOCKS5 proxy per account.

Redirect URL in Kick must match SaturX: http://localhost:8080/oauth/callback (same host/port as this dashboard; override with KICK_REDIRECT_URI in .env if needed).

Use the same host you use in the browser (localhost vs 127.0.0.1) — add both in Kick if needed.
